# Muhammad Irfan — HSE / Safety Officer Portfolio

A clean, professional personal portfolio showcasing HSE certifications, site safety experience, and skills, with full dark/light theme support.

## ✨ Features
- **Modern UI/UX:** Glassmorphism cards, smooth micro-animations, fully responsive layout.
- **Dark & Light Theme:** Toggle in the navbar, persisted across visits, respects system preference on first load.
- **Certifications Gallery:** NEBOSH, IOSH, OSHA, ISO 45001, and more — presented cleanly without exposing certificate numbers or QR codes.
- **Downloadable Resume:** A clean, generated one-page PDF resume.
- **Integrated Contact Form:** Sends messages via `FormSubmit.co` without needing a backend.

## 🛠️ Built With
- **React.js (19)** — Core UI framework
- **TypeScript** — Type-safe code
- **Vite** — Development and build tool
- **Vanilla CSS** — Custom theme-token system, no heavy CSS framework

## 💻 Running Locally

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## 📦 Build

```bash
npm run build
npm run preview
```
